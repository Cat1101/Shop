# AGENTS.md

## Проект

- `apps/web` — витрина на Next.js с App Router.
- `apps/api` — HTTP API на NestJS. Модули группируются по предметной области.
- `infra/postgres/init` — начальная схема PostgreSQL и демоданные для нового тома.
- `compose.yaml` — локальное окружение с витриной, API и PostgreSQL.

## Рабочий процесс

- Работай в отдельном Git worktree. Перед правками проверь текущую ветку и `git status`.
- Делай небольшие тематические коммиты. Проверяй diff перед коммитом и сохраняй пользовательские изменения.
- После изменения зависимостей обновляй и коммить корневой `package-lock.json`.
- Локальный запуск: `docker compose up --build -d --wait`. Проверь витрину на порту 3000 и `/api/health` на порту 3001.
- Остановка: `docker compose down`. Береги том PostgreSQL и данные в нём.
- Для уже существующих баз меняй схему явными версионированными миграциями. Скрипты начальной загрузки выполняются только для пустого тома.

## Код и данные

- Пиши читаемый TypeScript в строгом режиме. Используй понятные имена, небольшие функции и явные типы на границах API.
- Проверяй входные данные на сервере. Передавай значения в SQL параметрами и храни денежные суммы целыми числами в копейках.
- Коммить только примеры локальных настроек. Секреты и реальные `.env` оставляй вне Git.
- Если понадобится Python, соблюдай PEP 8: одна команда на строку, без точек с запятой, отступы 4 пробела, пробелы вокруг операторов, понятные имена и небольшие функции. Не сокращай код ради компактности.
